# 仓配订单汇总小助手 (AstrBot 专属插件)

适用于 **AstrBot** 的仓配订单汇总插件，支持在 QQ、微信、企微、飞书等任意平台中直接接收 Excel 单据，自动完成计算汇总并将结果表格回传给用户。

## 功能特色
1. **智能单据识别**：直接将 Excel 发给机器人，无需复杂配置，自动识别送货单、入库单、采购表、库存表等；
2. **多平台无缝发送**：借助 AstrBot 的消息组件，直接向用户原路发送生成的 Excel 附件；
3. **大模型赋能**：支持智谱 AI `GLM-4-Flash`、硅基流动等免费大模型，可通过自然语言（“帮我汇总刚刚的送货单”）直接唤醒工具处理；
4. **斜杠指令支持**：支持 `/excel`、`/送货单`、`/库存更新`、`/采购需求`、`/开票对账`、`/费用核销`、`/重置` 等丰富指令。

## 环境变量配置（可选）
- `EXCEL_BOT_URL`：后端 Node.js 算力服务地址（Docker 内部默认为 `http://excel-bot:3000`）。
- `EXCEL_BOT_SHARED_DIR`：跨容器共享文件目录（默认为 `/tmp/excel-bot-sessions`）。
